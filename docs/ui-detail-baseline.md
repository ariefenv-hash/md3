# ui-detail-baseline — 「精致与细节」参照基准（外部 SPA 模式提取）

> **来源**：维护者 2026-11-07 指令——上传 4 个参照单页应用（下称「参照组」），要求
> 反思「何为精致与细节」；**明确约束：不得照抄**——参照组由无仓库上下文的会话生成，
> 其涟漪等实现仍是旧方案，仓库侧已有更强基建。
> **用途**：本文件是 #243「新增应用视觉准入清单」的参照输入 + 各实例共享的质量语言，
> 供新增/补课应用自查；**不是新门禁**（断言车道归 #230，不在此另起）。
> **边界**：只谈观感与细节模式，不重做 #229 的摸底矩阵，不替代 #244 的采用率实测。

## 一、参照组样本

| 应用 | 体量 | 领域 | 最值得学的点 |
|---|---|---|---|
| 字间（打字练习） | ~950 行 | 输入型 | 实时统计、入场编排、结果页仪式感、图表细节、IME 健壮性 |
| foldr（压缩解压） | ~1000 行 | 工具型 | 图标 font-variation 悬停渐变、列表逐项入场（延迟封顶）、meta theme-color 跟随 |

## 二、「精致与细节」模式清单（学什么）

1. **运动令牌语义化**：`:root` 声明缓动/时长语义令牌（emphasized / decelerate /
   accelerate / standard），全文件不出现第二次手写曲线——这正是 #239 的诉求，
   v10.45 已落地 `--md-easing-*` / `--md-duration-*` 真源，应用侧一律 var() 引用。
2. **状态层系统化**：hover/active 不写死色值，用
   `color-mix(in srgb, currentColor 9%, transparent)`（≈MD3 hover 8%/pressed 12% 档）
   ——换主题零维护。仓库令牌层已有 `--md-state-hover/pressed`，应用未接入的按 #244 补。
3. **入场编排**：列表/分区入场用 `opacity:0 预置 + forwards 补间 + 逐项 stagger`
   （`animation-delay: calc(var(--i) * 70ms)`，延迟封顶防长列表拖沓），配合双 rAF
   触发类切换保证首帧态确定——#245「基础档：列表进入」的现成范式。
4. **数字有生命**：结果数字 countUp（四次方 ease-out）+ `font-feature-settings:'tnum'`
   防抖动 + display 级字重/负字距 + 宽字距大写小标签的排版对仗——结果页是「标志性时刻」。
5. **主题切换全局色彩过渡**：切换瞬间给根节点挂瞬态类统一 0.45s 过渡（模拟 Android
   动态取色的平滑换肤），480ms 后摘除——比逐元素各写 transition 便宜且整齐。
6. **图表细节**：Canvas 按 DPR 缩放防糊、悬停十字 tooltip、均值虚线、draw-in 生长动画、
   `document.fonts.ready` 后重测量——数据可视化三件套一个都不能少。
7. **微反馈全集**：snackbar（inverse-surface 反色）、kbd 键帽样式、`::selection` 主题化、
   卡片 `:focus-within` 高亮、`scrollbar-gutter: stable` 防布局跳动——小东西见真章。
8. **生命周期健壮性**：`visibilitychange` 暂停计时、IME composition（isComposing/229）
   分流、resize 后重测量、localStorage 偏好持久化——精致=处处可预期。
9. **空状态与结果仪式**：完成页逐项入场（res-in 序列）而非整体闪现；空状态有插画/文案
   而非留白（#243 准入清单第 7 项的参照实现）。
10. **音效合成**：WebAudio 双振荡器轻击键声、成功/错误双音色、静音开关持久化——
    触觉维度的细节。仓库已有 aosp 音频资产，应用侧合成音效仅限场景化补充。

## 三、「不照抄清单」（负向边界，同等重要）

| 参照组做法 | 为什么不抄 | 仓库正确姿势 |
|---|---|---|
| CSS-scale 触点涟漪（span 定位 + scale 动画） | 旧方案：无波前迁移、无 sparkle、无中断续接 | `js/aosp/expressive-ripple.js`（WebGL/AGSL 逐行移植）与 `apps/_shared/m3e-ripple.js`（Canvas2D 版）为准 |
| 自创弹簧近似曲线（如 `.34,1.56,.64,1`） | 参数无出处，过冲幅度不可控 | #239 权威值表六档，或 `js/spring.js` SpringSolver 闭式解 |
| 令牌命名各起一套（--emph/--ease-emph/--ease-spring） | 三套命名并存 = 新的漂移土壤 | 统一 `--md-easing-*` / `--md-duration-*` |
| 独立页假设（直写 localStorage、CDN 字体直链、无宿主取色） | 参照组是孤岛页面，仓库应用是宿主 iframe 子应用 | `_shared/md3-tokens.css` 令牌层 + 宿主 `--md-h` 动态取色联动 + `--md-text-font` 字体契约 |
| 单文件自包含无门禁 | 参照组没有评分卡/构建期检查，依赖作者自觉 | 8 项评分卡（#230）+ 准入 lint（#228）必须过 |

## 五、给后续实例的三句话

1. 新应用动工前：先读 `scripts/app-template.html` 头注与本文件第二节，再动手。
2. 写动画时：曲线/时长只准 var() 引用令牌；手写 cubic-bezier 会被 v239 负向锚拦下
   （`tests/motion-tokens.test.js` B3）。
3. 想加涟漪时：不要写 CSS-scale 涟漪（参照组旧方案）；接 `m3e-ripple.js` 两行契约，
   宿主侧已有 Expressive 全量移植。
