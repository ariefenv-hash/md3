# 新增应用视觉基线（#243 · V 清单 8 项）

> 议题：#243「新增应用颜值结构性落后：新增组视觉达标率 10% vs 存量 33%」§① 建议动作的落地件。
> 原则：**不重做 #229 摸底、不另起评分卡基建** —— V 清单挂在既有 `scripts/audit-app-quality.mjs`
>（#228 全量扫描 / #227 滑块门禁 / #230 九项制 / #244 视觉令牌面）引擎之内，与九项制并行独立段，
> 九项制的 `ITEM_KEYS`、阈值、基线水位一概不动。

## 一、V 清单 8 项与机器口径

| 项 | 名称 | 机器判定口径（合并应用目录 .html/.css/.js/.mjs 后判定） |
|---|---|---|
| V1 | 动态取色 | 继承 A 项口径：`var(--md-` ≥15 且 ≥4 处/100 行（与 #229 矩阵对齐，不另立阈值） |
| V2 | 字体阶梯 | `var(--md-font,` / `var(--md-text-font` 消费 ≥1（剥注释后，消费非提及；`--md-font-num` 不误匹配） |
| V3 | 圆角/形状 | `var(--md-r-` 消费 ≥2（--md-r-xs/sm/md/lg/xl/full） |
| V4 | 状态层 | `var(--md-state-` 消费 ≥1（hover 8% / pressed 12% 标准浓度） |
| V5 | 按压反馈 | `:active` / `.pressed` / `pressRipple` / `squeeze-row` / `*-ripple` ≥1（剥注释防文档误伤） |
| V6 | 开屏动效 | `@keyframes` 定义 ≥1 **且** `animation:` 应用 ≥1（双要件，剥注释） |
| V7 | 空状态 | `暂无` / `空状态` / `empty-state` / `数据为空` / `空空如也` / `没有内容` / `无内容` ≥1（剥注释） |
| V8 | 深色与窄屏 | `var(--md-surface`/`var(--md-on-surface` 消费 ≥1（深色随宿主令牌联动）**且**（`@media max-width` ≥1 或 B 项通过） |

分档：8 项中 **≥7 达标 / 4–6 偏薄 / ≤3 严重**（与九项制同比例）。

**报告级非硬门禁**（#243 §② 明确「未达基线给分档而非硬阻断」，防 #235 门禁连红→部署全跳过复发）：
V 清单结果只打印 + 进 `--json` 的 `visual` 段，不进 `hardFailures`；水位回退只 warn 不 fail。

## 二、脚手架内建（新建即达标，#243 §③）

- `scripts/app-template-multi/` 与 `scripts/app-template.html` 双模板 **8/8 全达标**（v10.63 开卡时实测）：
  - V2/V4/V8：`md3-tokens.css` 令牌消费（v10.53 #246 状态层示范内建）
  - V3：`--md-r-full/--md-r-lg/--md-r-md/--md-r-sm` 分级圆角
  - V5：`.md3-btn:active` 缩放 + `squeeze-row` 整排按压联动
  - V6：`md-fade-in` 开屏动效
  - V7：`.empty-state` 空状态示范块（图标 + 主文案 + 辅助文案，列表/详情类应用直接复用改文案）
- `npm run new-app`（单文件与 `--multi` 均适用）生成的应用天然带全 8 项基线；
  生成后 CLI 指引会提示 V 清单口径位置。

## 三、水位与运行

```bash
node scripts/audit-app-quality.mjs                        # 全量 41+ 应用：九项制 + V 清单报告
node scripts/audit-app-quality.mjs --json                 # 机器可读（含 visual.tally / visual.apps）
node scripts/audit-app-quality.mjs --write-visual-baseline # 开卡/更新 V 清单水位 scripts/visual-baseline.json
```

- `scripts/visual-baseline.json`：开卡快照（41 应用 + 2 模板，逐项 V1–V8 布尔；v10.64 合流终树复跑生成，
  与 v10.63 开卡数字逐项一致——对侧九项制收口面与 V 面正交的实证）。
  「曾经通过」的 V 项掉线时打印 `⚠ 水位回退（报告级）`——提示整改，不阻断构建。
- 新应用落盘自动纳入（复用 #228 全量扫描，零硬编码清单），不在此文件内 = 新应用，由分档报告管。
