## 六、口径局限（诚实标注）

1. **静态计数 ≠ 运行时观感**（#229 同款局限）：裸色计数含 SVG `fill`、`data:image` URI、画布绘制参数，camera/clock-app 的面上重值主要来自 SVG 资产与表盘/取景器场景，非主题层失血；A 门槛对超长文件偏严（music 3142 行 md 86=密 2.7 判 ✗ 即此效应，见二节矩阵）。
2. **暗色继承免费**：令牌消费者随 `md3-tokens.css` 的 `:root` 明暗分支自动获得暗色（宿主注入 `data-theme-mode`），故本表不设独立「暗色分支」列；**硬编码色即破坏暗色**，其规模由「裸」列相对反映。
3. **状态层 R123 实测 0/41（R124 后 3/41）不代表零状态反馈**：19 家存在手写 `:hover/:active` 面，只是未走令牌通道——整改含义是「换通道」而非「从零补功能」（P0 三家已完成换通道，其余 16 家仍待逐批推进）。
4. 首提日期用 `git log --reverse -1 -- <dir>` 近似；41 应用与 #229 分组逐一吻合，矩阵后零新增（v10.33→v10.50 期间无新应用目录）。
