## 三、新增组件取值规则

1. 先按语义选层带，再在带内挑一个**未占用**的整数；同层内按语义相邻递增（+1 / +10），不要跨带跳跃。
2. **禁止**用 `9999` / `10000` / `99000` 这类"随手取大值"来解遮挡；任何进入 Z5/Z6 的取值必须在本表登记理由。
3. 父子层叠优先靠 DOM 顺序与 `position` 建立上下文，而非抬高数值。
4. 后续若要引入 `--z-*` 变量：先做「裸数字检测」audit（提示级），再逐带迁移；迁移属独立议题，不在本卡范围。

## 四、与既有缺陷的关系

- #225（根壳入口开窗遮挡）、#248（导航设置形态）属"未分带导致的实测撞车"；本表给出归档位置，不追溯改值。
- 本卡只落规范与映射，**零 CSS 改动、零滚版**。
