平板 Overview 任务网格 · AOSP 同构改造：后台布局引擎统一三形态

2026-10-11 · commit a3dcc67 · 测试 759/759 全绿 · E2E 25/25 PASS

①网格带垂直居中

最近任务页的焦点卡与网格卡共享一条垂直居中带：ty = deckH/2-(10+focusH/2)，修复了旧版"焦点卡右上偏移"的问题，焦点卡与两行网格卡上下边缘精确对齐。

②固定两行网格（AOSP 同构）

替代旧的 ceil(n/2) 行数自适应：单元格高度按 AOSP calculateGridTaskSize 公式计算——cellScale=(focusH-gap)/(2*focusH)，无论卡片数量多少，网格始终保持两行结构，与 Android 12L+ 原生 Overview 行为一致。

③贪心行交替 + 最新卡贴邻

网格卡按 row=gi%2, p=floor(gi/2) 交替落入两行，最新的网格卡始终紧邻焦点卡；行宽遵循 topRowWidth ≤ bottomRowWidth（对应 AOSP updateGridProperties）。

④行右锚定 + 横向"移入空位"

两行网格整体右锚定于焦点卡左缘（cx=gridRight-p*(cellW+gap)-cellW/2），向左生长——新卡像原生系统一样"横向移入空位"。

⑤操作行双通道测量修复

操作行移到焦点卡正下方：先用临时 absolute 脱离 flex 流，再用 getBoundingClientRect 换算容器相对坐标，解决了 max-width:540px 容器陷阱与 30px 陈旧 flex 测量值。渲染最近卡、偏好热切换、空态重置三处均已接线。

⑥宽度自适应缩放解方程

缩放不再用均匀 scale（gap 不会跟着缩放导致溢出），改为解方程 perRow*s*focusW+(perRow-1)*gap=gridW 精确求 s，并设 0.2 下限。
